# LyricsMC

LyricsMC, dinlediğiniz müziği Minecraft deneyimine taşıyan bir Fabric modudur. Çalan şarkının bilgilerini ve müzikle senkronize sözlerini oyun içinde gösterir. Karaoke çubuğu, 3D hologram oynatıcı, özelleştirilebilir gökyüzleri, kozmetik dolabı ve diğer LyricsMC oyuncularıyla paylaşılabilen hareketler sunar.

Minecraft **1.21.4** ve **1.21.11** sürümlerini destekler.
